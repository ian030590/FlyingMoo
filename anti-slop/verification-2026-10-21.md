# FlyingMoo v1.0.1 修正驗證

已修正前次檢視列出的九項問題，方向與理由見 `DESIGN.md`。

## 驗證與限制

- `npm test`：32 項通過，包含畫面流程、Worker 訊息與四方向校正回歸測試。
- `cargo test --release --manifest-path src-tauri/Cargo.toml`：1 項通過，確認未實作的 Tobii 不會回報有效姿態或連線成功，並可重複啟停。
- `npm run build`：產生 Windows x64 GUI 可攜式 EXE，核對 SHA-256 與隨附文件。
- Chromium 與封裝後 WebView2：完成下列操作，沒有頁面例外或資產請求失敗。
- 攝影機測試以 `canvas.captureStream(30)` 產生持續影格，實際執行本機 MediaPipe JS、WASM 與模型推論。
- 方向控制使用合成姿態。真實鏡頭、光線、坐姿與角度精度未實測；此版本尚未支援 Tobii Eye Tracker 5。

## 操作紀錄

| 操作 | 結果 |
| --- | --- |
| 設定、說明彈窗 | Tab 保持在彈窗內；Esc、關閉及確認可關閉；焦點還原 |
| 左右、上下滑桿 | 鍵盤操作後顯示值同步更新 |
| 預覽、鏡像核取方塊 | 可切換、儲存、重設，標籤高度至少 44px |
| 相機權限 | 拒絕時顯示文字原因 |
| 開始、方向鍵、音效 | 可開始飛行與移動；音效可用滑鼠及 Space 切換；HUD 焦點不阻擋方向鍵 |
| 暫停、繼續 | 保留原本 20 秒、7 次閃避的本局進度 |
| 倒數時 Esc、返回選單 | 原倒數確實取消，等待超過原倒數時間仍留在選單 |
| 校正錯誤、重試、調整靈敏度、改用鍵盤 | 錯誤可見；重試重新啟動來源；設定可關閉；備援回到選單 |
| 中立、四方向校正、開始飛行 | 有效訊息帶 sessionId，驗證可完成並開始 |
| HUD 與暫停重新置中 | 採用新鮮姿態，暫停後須穩定回正才能繼續 |
| 追蹤資料停止更新 | 逾時暫停並停用繼續 |
| 回選單切換來源 | 顯示真正來源選項並移入焦點；HUD 同步顯示來源 |
| 結束、再玩一次、返回選單 | 顯示本局結果、可重玩或返回選單 |
| Tobii 選項及原生指令 | 明示尚未支援；選項停用，指令回傳錯誤 |
| 800×600、600×400、390×844 | 設定及說明可捲動操作，沒有水平溢位 |
