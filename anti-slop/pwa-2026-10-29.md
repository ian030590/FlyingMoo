# PWA 變更驗證

沿用 DESIGN.md 的星空遊戲、牛羊角色與系統中文字型。ENERGY 2 / RHYTHM 1 / MOTION 1。此次僅增加安裝、全螢幕與裝置連線說明，PWA 圖示由既有牛角色轉出。

- Hard Gate PASS：1280×800、375×812、812×375 的主選單與設定視窗沒有橫向溢出；新按鈕使用既有 44px 最小尺寸、focus-visible 與高對比配色。瀏覽器確認來源切換、設定開關與儲存、說明、全螢幕切換、鍵盤遊戲、暫停／繼續、CSV 下載及離線模型載入，無頁面例外與 HTTP 資源錯誤。沒有加入虛構資料或無效連結。
- Purpose Gate PASS：沿用既有深藍背景與綠色主要動作；下載／說明連結使用既有青色，以便在深色底辨識。保留原有遊戲視覺與動畫，沒有新增裝飾效果。
- Liveliness PASS：維持原有牛羊角色、遊戲畫布焦點與設定分組間距；安裝與全螢幕動作放在既有按鈕群組，沒有新增行銷區塊。
- Craftsmanship PASS：89 項 JavaScript 與 15 項 Rust 測試通過；manifest 無安裝條件錯誤；子路徑、模型與 WASM 離線載入通過。Tobii 使用可執行的本機橋接，UI 清楚說明缺少裝置、橋接權限、全螢幕與下載行為。

以上是變更範圍的程式及自動瀏覽器驗證。真人操作、實體 ET5、多螢幕／混合 DPI 與手機實機安裝尚未驗收，詳見該版 release notes。
