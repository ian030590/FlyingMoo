FlyingMoo v1.2.0 讓 **Tobii 場次完整記錄頭動與眼動資料**，並檢查 VOR 練習時受試者是否注視中央十字；練習前也可設定羊飛來的速度、固定練習時間或無限加速模式。下載 `FlyingMoo_1.2.0_x64-portable.exe` 後直接執行。

### Tobii 頭動與眼動紀錄

- v1.1.0 的 Tobii 只做即時頭控、不建立 CSV，因此沒有任何資料。本版起 Tobii 場次與攝影機、鍵盤一樣，每局在 `Data` 寫一份 CSV。
- 每一筆 Tobii 樣本各寫一列：`tobii-head` 為頭部旋轉與位置，`tobii-gaze` 為視線落點與左右眼位置（mm），都附裝置原始時間戳。樣本先存入原生佇列再逐筆寫出，不會因畫面更新而略過。
- 視線換算到遊戲視窗座標，與當時畫面上的十字比較，寫入像素、mm 與視角偏差，以及是否在容許範圍內。
- 每局另寫 `_session.json` 摘要：練習設定、成績、注視統計、Tobii 裝置與螢幕資訊、遺失樣本數。

### VOR 注視檢查

- 以眼睛到螢幕的距離換算視角，偏差不超過容許角度（預設 3°，1–10° 可調）即判定為注視十字。
- 遊戲中 HUD 顯示注視比例；結果畫面列出整體與轉頭期間的注視比例及平均偏差。
- 設定可開啟視線點，實驗者能即時看到受試者的視線位置。
- 校正畫面會檢查遊戲所在螢幕與 Tobii 設定的螢幕是否相符，不符時提醒視線位置可能不準。

### 練習模式與速度

- **固定時間**：羊以固定速度飛來，1–30 分鐘，時間到即結束；碰撞計次但不中斷。
- **無限加速**：每分鐘依設定比例（10–200%）加速，沒有上限，碰撞即結束。預設 86%，與先前版本的加速相同。
- 起始速度 0.5–3 倍，設定畫面會顯示羊從出現到抵達所需的秒數。
- CSV 新增 `game_mode`、`run_time_s`、`speed_multiplier`、`dodged_count`、`hit_count` 與 `head_directions` 欄位。

### 使用方式

1. 安裝 Tobii Experience，接上 ET5，在 Tobii Experience 完成**螢幕設定**與校準。
2. 把遊戲視窗放在裝有 ET5 的螢幕上，主選單選「Tobii Eye Tracker 5」。
3. 在「練習、裝置與靈敏度設定」選擇模式、速度與注視容許角度，再按「開始遊戲」。
4. 校正畫面下方會顯示眼動紀錄狀態；完成中立點及四方向校正後開始飛行。

### 注意事項

- **授權**：Tobii 消費級產品（含 ET5）的條款將儲存或傳輸眼動資料列為分析用途，需另向 Tobii 取得授權。本版以 `STORE_OR_TRANSFER_TRUE` 模式連線並寫入檔案；用於研究前請確認授權狀態。
- 視線精度取決於 Tobii Experience 的校準與螢幕設定，並非醫療等級量測。VOR gain 等指標須由研究者以 CSV 自行計算。
- 若遊戲視窗不在 ET5 所在螢幕，像素與角度欄仍會寫入，但不可直接採信；摘要中的 `display.check.matches` 會是 false。

### 驗證與限制

**實機驗證（ET5 + 封裝 EXE）**

- 約 27 秒的 Tobii 場次寫出 876 列頭部與 876 列視線樣本，皆約 33 Hz、時間戳嚴格遞增、0 筆遺失；`_session.json` 一併寫出，螢幕比例檢查與實際螢幕相符。
- 碰撞列都對應到實際的頭部列；固定時間模式碰撞後繼續，HUD 顯示剩餘時間、撞羊數、速度與注視比例。
- 實機測試中發現同一幀視線偶爾被拆成兩列，已修正並重測。
- 連續啟停 20 次、舊 session 隔離、缺少 Tobii DLL 時的錯誤提示與鍵盤遊玩，皆重新確認。

**合成測試**

- 85 項 JavaScript 與 8 項原生測試通過，涵蓋視線換算（視窗位移、第二螢幕、DPI 縮放）、視角與注視判定、CSV 欄位、場次摘要、練習模式的時間到結束與無上限加速。
- 實機測試中，進入遊戲是由測試程式設定中立點並啟動倒數，非受試者完成四方向校正；頭部與視線資料仍為實機資料。

**尚未驗收**

- 受試者依指示注視十字並轉頭的受控測試；實機測得的注視比例來自未受指示的使用者，不代表判定準確度。
- 3° 預設容許角度是否適合研究用途，請依研究設計調整。
- 長時間場次、USB 拔插與多螢幕配置。
