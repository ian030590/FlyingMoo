FlyingMoo v1.1.0 新增 **Tobii Eye Tracker 5 即時頭部控制**，現在可選擇鍵盤、攝影機或 Tobii 操作。下載 `FlyingMoo_1.1.0_x64-portable.exe` 後直接執行。

### 新增 Tobii 頭控

- Windows 桌面版開放 Tobii Eye Tracker 5 選項，讀取裝置的真實頭部旋轉與位置。
- 接入既有中立點校正、四方向驗證、各方向靈敏度、One Euro Filter、重新置中與暫停／恢復流程。
- 使用本機 Tobii Experience 附帶的 Stream Engine 4.x；已在 4.25.0.3 與 ET5 實機驗證。EXE 不內嵌或散布 Tobii SDK DLL。
- 缺少官方元件、裝置未連接、頭位不可用或存取失敗時顯示對應訊息，可重試或改用其他來源。

### 串流與資料處理

- 將 SDK 樣本時間映射至遊戲單調時鐘；重讀同一筆資料不會更新有效時間。
- 拒用重複、舊 session、無效角度及超過 250 ms 的姿態；追蹤失效時清空方向並暫停。
- 啟停指令依序處理，切換來源與停止時釋放訂閱、裝置及原生資源，避免舊連線繼續控制。
- **Tobii 僅即時控制，不建立 CSV 或匯出追蹤歷程。** 攝影機與鍵盤原有的 CSV 紀錄流程維持不變。

### 使用方式

1. 安裝 Tobii Experience 與官方驅動，接上 ET5 並完成官方校準。
2. 開啟 EXE，選擇「Tobii Eye Tracker 5」，按「開始遊戲」。
3. 依畫面完成中立點及四方向校正，再開始飛行。

需要 Windows x64 與 Microsoft Edge WebView2 Runtime。Tobii 來源只在桌面版啟用；未安裝 Tobii 軟體仍可使用鍵盤或攝影機。

### 驗證與限制

- 72 項 JavaScript 測試與 4 項原生測試通過，包含合成姿態的中立點／四方向校正及串流生命週期檢查。
- 封裝 EXE 已完成 ET5 → Rust → IPC → 前端實機驗證，取得有效旋轉及位置、完成中立校正並進入方向驗證；連續啟停 20 次及舊 session 隔離通過。
- 模擬缺少 Tobii DLL 時，會顯示安裝提示，鍵盤遊戲仍可開始，攝影機選項仍可選。
- 實機四方向動作、USB 拔插與長時間穩定性尚未驗收；請依遊戲校正畫面確認方向。
- EXE 所在資料夾須可寫入，供程式建立 `Data` 及保存攝影機／鍵盤場次的 CSV。
