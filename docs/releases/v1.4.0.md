# FlyingMoo v1.4.0

替換牛羊叫聲，並將遊戲內頭位校正改為選用。網頁與 PWA 位於 [FlyingMoo](https://ian030590.github.io/FlyingMoo/)。

- 使用提供的錄音分離豬、牛、羊叫聲，進行取樣降噪、高低通濾波、動態壓縮、淡入淡出及響度調整。原始錄音不改寫；分離 WAV 與處理報告放在 `assets/processed/`，另保留一份牛叫備選。
- 遊戲牛羊音效改為後製 MP3，約 −14.4 LUFS；保留羊通過／碰撞、牛開場／間歇播放、重疊及靜音行為。豬叫另存，沒有新增豬角色。
- 「開始遊戲／再玩一次」不再強制完成中立點採集與四方向驗證。同一來源、同一攝影機沿用本次中立點；首次直接開始等待有效頭位並置中，之後仍可按 `R` 重新置中。
- 主選單與結果畫面加入「校正頭位後開始／重玩（選用）」，可主動進行原有完整校正。切換來源或攝影機時不沿用另一裝置的中立點。
- 保留有效性、時間戳、250 ms 過期與追蹤中斷暫停保護；未取得有效頭位時不直接飛行。
- PWA 建置先清除舊的生成目錄，避免已移除的舊音效殘留在部署產物。

## 驗證範圍

- 合成測試：94 項 JavaScript 測試通過，包括攝影機與 Tobii 撞羊後重玩、沿用中立點、首次有效姿態、手動完整校正與裝置切換。
- 自動瀏覽器：以合成姿態驅動實際遊戲碰撞，確認一般重玩直接倒數且中立點不變、手動校正仍可進入；1280×800、375×812、812×375 無橫向溢出，無頁面例外。
- 音效：FFmpeg 測量 WAV 與 MP3 的實際 LUFS／真峰；瀏覽器成功解碼並播放兩份新 MP3。音效類別依使用者確認的順序切割，尚未進行人工聽感驗收。
- 尚未驗收：真人攝影機操作、實體 ET5 重玩與校正、多螢幕／混合 DPI 對位、手機實機安裝。合成姿態與可建置不代表完整硬體驗收。

## 下載

- `FlyingMoo_1.4.0_x64-portable.exe`：Windows 桌面遊戲。
- `FlyingMoo_TobiiBridge_1.4.0_x64.exe`：網頁／PWA 的 Windows 本機 Tobii 橋接。
- `SHA256SUMS.txt`：兩份 EXE 的 SHA-256。

已安裝的 PWA 請先結束練習，關閉所有遊戲網頁及 PWA 視窗後再開啟，以套用新音效與操作流程。
