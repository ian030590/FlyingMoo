# FlyingMoo v1.3.0

新增 [GitHub Pages 網頁與 PWA](https://ian030590.github.io/FlyingMoo/)，保留鍵盤、MediaPipe 攝影機頭部追蹤及 Tobii 操作。詳見 [PWA 使用說明](../PWA.md)。

- 支援安裝至電腦與手機主畫面；首次下載完整遊戲、圖片、音效與 MediaPipe 模型後可離線使用。
- 新增 Windows Tobii 本機橋接 EXE，重用原有 Stream Engine、時間戳與樣本佇列，讓網頁／PWA 讀取頭部姿態、視線及眼睛位置。
- Tobii 橋接僅監聽 loopback，限制來源與單一分頁；停止讀取五秒後釋放裝置。
- 網頁需使用遊戲的全螢幕按鈕，才計算注視十字的距離與角度；一般視窗保留原始樣本，不產生注視判定。
- 加入 GitHub Actions Pages 部署。新版在所有舊視窗關閉後套用，避免中斷練習。

## 驗證範圍

- 合成測試：89 項 JavaScript 單元測試與 15 項 Rust 單元測試通過，涵蓋遊戲、校正、瀏覽器橋接請求、連線失敗、全螢幕座標、service worker 範圍、原有資料流、CSV 與工作階段隔離。
- 自動瀏覽器驗證：`/FlyingMoo/` 子路徑、manifest 安裝條件、30 個離線快取項目、鍵盤操作、CSV 下載、全螢幕切換，以及 1280×800、375×812、812×375 尺寸通過。斷網重開後，以模擬攝影機成功載入 MediaPipe WASM 與模型，進入等待臉部狀態，無頁面例外或 HTTP 資源錯誤。
- 本機橋接驗證：已執行 Windows EXE，確認 CORS／本機網路 preflight、來源與 Host 限制、分頁隔離、五秒閒置釋放。當前環境回報 `TOBII_DEVICE_ABSENT`，缺少裝置的錯誤路徑已確認。
- 尚未驗收：真人攝影機四方向操作、實體 ET5 端到端操作、真實多螢幕與混合 DPI 對位、手機實機安裝。模型可載入、合成姿態與程式可建置，不代表完整硬體驗收。

## 下載

- `FlyingMoo_1.3.0_x64-portable.exe`：Windows 桌面版。
- `FlyingMoo_TobiiBridge_1.3.0_x64.exe`：網頁／PWA 使用的 Windows 本機橋接，使用時保持視窗開啟。
- `SHA256SUMS.txt`：兩份 EXE 的 SHA-256。

Tobii 仍需官方軟體與驅動；不附 SDK DLL。瀏覽器場次結束時下載 CSV，請在關閉視窗前結束場次並允許下載。
